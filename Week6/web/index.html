Docker 微服務展示

七個容器各司其職：每個服務擁有自己的資料庫，服務之間用 API 與 RabbitMQ 溝通。

請求路徑

瀏覽器→Nginx→Node / Python / Rust
Node→DB（Node）　Node→事件→RabbitMQ→事件→Python→DB（Python）

服務狀態

留言板（Node.js）

Node.js 把留言寫入自己的資料庫，並發出 note.created 事件後立刻回應。

    留言統計（Python + RabbitMQ）

    Python 收到事件後才更新自己的資料庫，所以新增留言後數字會稍晚（約 1.5 秒）才變化。from_api 是啟動時呼叫 Node API 補齊的，from_events 是 RabbitMQ 送來的。
